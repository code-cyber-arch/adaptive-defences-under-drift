# Methods text: policy comparison and feedback robustness

Within the existing three-experiment design, Experiment 2 includes controls for reset-policy choice, and Experiments 1 and 2 include sensitivity analysis of protected-feedback availability. The existing RQ1 and RQ2 remain unchanged. The reset-policy comparison includes fixed responses, tabular Q-learning and deterministic policies that use the same state information as the learned controller. This comparison distinguishes the value of the available state representation from the ability of Q-learning to select useful actions.

The four-state representation combines the monitor alarm with recent error deterioration. With two available actions, the representation admits 16 deterministic mappings. Each mapping is assessed on a separate synthetic validation realization, and one mapping is selected by mean macro-F1 across the declared validation conditions. Ties are resolved by fewer committed resets and then mapping identifier. The selected mapping and the learned Q-tables are frozen before evaluation. An error-threshold policy using the same state variables provides a directly interpretable comparator.

The comparison uses SEA and Random RBF with disjoint validation and evaluation seeds. Three evaluation realizations per family are subjected to the same clean and poisoned conditions across all response methods. Predictions are recorded before candidate learning, and all compared methods retain the same candidate-screening rule. Fixed confirmed reset retains its buffered refit, whereas the deterministic and learned mappings reset from the current block; comparisons between these response types therefore include the difference in refitting strategy.

Protected-feedback robustness is assessed by varying usable feedback coverage and release delay. Five percent of observations remain reserved in every arm, while nested subsets corresponding to one, two or five percent of observations are released after one or five blocks. Keeping the reservation fixed preserves the training and scoring populations across settings. Unreleased protected observations are not returned to training. The experiment therefore measures sensitivity to usable protected information under a fixed reservation budget. All response policies remain frozen, and a candidate is rejected when no protected sample is available.

Macro-F1 measures predictive performance. Poison admission and legitimate withholding describe learning exposure, while committed resets, training visits and elapsed time describe operational costs. Comparisons are paired within stream realization, poisoning condition and feedback setting. Stream seeds and learned-policy seeds are reported separately; repeated policy evaluations on one realization are not interpreted as independent datasets.
