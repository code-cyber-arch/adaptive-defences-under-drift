# Execution provenance

The main numbered folders and `results/per_dataset_study/` define the current thesis study. This directory retains historical source snapshots, execution contracts and the earlier implementation under `legacy_study/` for traceability. Archived results are not pooled into the current findings. Original contract contents and file hashes are preserved even where paths describe their original execution location.

The root publication manifest checks the files at their current repository locations. Historical manifests remain records of their original layouts.
