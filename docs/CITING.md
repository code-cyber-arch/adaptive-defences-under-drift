# Cite the experiment repository

`CITATION.cff` identifies the software. Once the repository is published, use its public URL and a fixed tag or commit in the thesis. Keep the original repository citation when describing the origin of the adopted benchmark.

Suggested artifact statement after publication:

> The experiment code, settings, retained result tables and verification records are available in the Adaptive Defences under Drift repository. The cited version fixes the software and evidence used for this thesis. Large local artifacts and the original archive limits are described in the repository's data-availability statement.

Do not claim that the public repository includes complete raw traces unless those artifacts have also been deposited and linked. Do not describe the standalone migration as a new experimental execution.

GitHub supports citation metadata through a root `CITATION.cff` file: [GitHub citation-file documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files). Cite a released tag or exact commit so later development does not change the evidence identified in the thesis. A repository URL is not a DOI; no DOI has been assigned here.
